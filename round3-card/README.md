# 3회차 – 존중 메시지 카드 퍼뜨리기 (퍼뜨리기)

**목표:** 존중 메시지를 카드나 짧은 영상으로 만들어 **학생·교사·학부모**에게 퍼뜨립니다.
**시간:** 종례 10분 (만들기) + 집에서 공유 · **제출:** 공유 인증 캡처 1장

---

## 방법

1. **미리캔버스** 또는 **캔바**에서 '카드뉴스'나 '인스타 게시물' 템플릿을 고릅니다. 15초 숏폼도 가능합니다.
2. 존중 메시지 한 문장을 넣어 카드 1장을 만듭니다.
3. 아래 중 **한 곳 이상**에 공유합니다.
   - 반 단톡방 · 가족 단톡방 · 개인 SNS 스토리 · 선생님께 보내기
4. 공유한 화면을 캡처해서 폼에 업로드합니다.

## 카드 문구 예시

- "보내기 전에 3초, 읽는 사람을 생각해요"
- "읽씹 대신 '나중에 답할게' 한마디"
- "다른 생각 ≠ 틀린 생각"
- "현장에서도 온라인에서도, 인사부터 존중입니다"
- "엄마, 오늘도 고생 많으셨어요" (가족에게 보내는 존중)
- "선생님, 오늘 수업 감사했습니다" (교사에게 보내는 존중)
- 2회차 우수작의 '바꾼 표현'을 그대로 카드에 써도 됩니다.

## 구글폼 문항

1. 학년 / 학과 / 반 / 학번·이름 (상점 부여용)
2. 내 카드 문구 (단답형)
3. 공유한 곳 (체크박스: 반 단톡방 / 가족 / SNS / 선생님 / 기타)
4. 카드 이미지 업로드
5. 공유 인증 캡처 업로드

## ⚠ 캡처 주의

- 단톡방 캡처에는 **친구 이름·프로필 사진**이 보입니다. 학생이 가리고 올리도록 안내하고, 저장소에 넣을 때도 다시 확인합니다.
- 카드에 **본인 얼굴·실명**은 넣지 않습니다.

## 종례 멘트 (1분)

> "마지막 3회차예요. 미리캔버스로 존중 메시지 카드 한 장 만들어서
> 가족 단톡방이나 반 단톡방에 보내고, 보낸 화면 캡처해서 올려 주세요.
> 부모님께 '고생하셨어요' 한마디 카드도 좋아요. 친구 이름은 가리고 올리세요."
