# 3회차 – 존중 카드 퍼뜨리기 (퍼뜨리기)

**목표:** 완성된 존중 메시지 카드를 골라 **가족·친구·선생님**에게 보내며 존중을 퍼뜨립니다.
**시간:** 조·종례 5분 또는 수업 10분 · **제출:** 보낸 화면 캡처 · **보상:** 참여 학생 상점
**안내 페이지:** QR → **3회차 탭** (또는 주소 끝에 `#3`)

---

## 학생 활동

1. 안내 페이지 3회차 탭에서 카드 8장 중 하나를 고릅니다.
2. **'공유'**를 누르면 카톡으로 바로 보낼 수 있습니다. 공유가 안 되면 **'저장'**을 누릅니다.
3. **가족 단톡방 / 반 단톡방 / 선생님** 중 한 곳 이상에 보냅니다.
4. 보낸 화면을 캡처해서 폼에 제출합니다.

## 카드 8장 (`docs/cards/`)

| # | 받는 사람 | 문구 |
|---|---|---|
| 1 | 친구에게 | 보내기 전 3초, 읽는 사람을 생각해요 |
| 2 | 친구에게 | 다른 생각은 틀린 생각이 아니에요 |
| 3 | 친구에게 | 읽씹 대신 "확인했어!" 한마디 |
| 4 | 가족에게 | 오늘도 고생 많으셨어요. 늘 고마워요 |
| 5 | 선생님께 | 선생님, 오늘 수업 감사합니다 |
| 6 | 현장실습·직장 | 인사부터 존중입니다 |
| 7 | 현장실습·직장 | 모르면 물어보는 것도 예의예요 |
| 8 | 모두에게 | 얼굴 보고 못 할 말은 온라인에서도 하지 않아요 |

문구를 바꾸거나 2회차 우수작을 카드로 추가하려면:
1. `scripts/make_cards.py`의 `CARDS` 목록을 고칩니다.
2. `python scripts/make_cards.py`를 실행합니다.
3. `docs/index.html`의 `CARD_VERSION` 숫자를 1 올립니다. 카드 수가 바뀌었다면 `CARD_COUNT`도 고칩니다.
4. 커밋하고 push합니다.

## 수업 시간에 할 때 (10분)

| 단계 | 시간 | 활동 |
|---|---|---|
| 도입 | 2분 | 3회차 탭의 카드 8장을 화면에 띄우고 "오늘 누구에게 보내고 싶나요?" 물어보기 |
| 활동 | 5분 | 카드 골라 보내고, 보낸 화면 캡처 제출 |
| 마무리 | 3분 | 바로 답장이 온 학생이 있으면 소개 (부모님·선생님 반응) → 존중은 받는 사람에게서 다시 돌아온다는 이야기로 마무리 |
