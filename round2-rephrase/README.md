# 2회차 – 말 바꾸기 챌린지: 찾고 → 바꾸고 → 실천하기 (해보기)

**목표:** 인터넷에서 실제 안 좋은 글을 보고, 존중하는 말로 어떻게 바꿀지 고민한 뒤 **직접 실천**합니다.
**시간:** 조·종례 10분 또는 수업 15분 · **제출:** 바꾼 표현 + 실천 캡처 · **보상:** 참여 학생 상점, 학과별 우수작 추가 상점
**안내 페이지:** QR → **2회차 탭** (또는 주소 끝에 `#2`)

---

## 학생 활동

1. **찾기**: 유튜브·뉴스 댓글·커뮤니티에서 상처 주는 댓글이나 글을 하나 찾습니다.
2. **바꾸기**: 같은 뜻을 존중하는 말로 바꿔서 폼에 적습니다.
3. **실천하기**: 아래 중 하나를 실제로 하고 캡처합니다.
   - 상처받았을 사람에게 **응원·존중 댓글** 달기
   - 욕설·혐오·괴롭힘 글 **신고하기** (신고 완료 화면 캡처)
   - 단톡방에서 **바꾼 말투로 한 번 말해 보기**

바꾸기 예시는 [예문 세트](examples.md)를 참고하세요. 현장실습·직장 상황(C 세트)을 골라도 됩니다.

## ⚠️ 안전 규칙 (안내할 때 꼭 말해 주세요)

- 악플 단 사람에게 **직접 따지거나 반박하지 않기**. 싸움이 커질 수 있습니다.
- 캡처에서 **다른 사람 아이디·프로필 사진 가리기**
- 너무 심한 글(혐오·성적인 글)은 일부러 찾지 않기
- 우리 학교 학생이 피해를 입는 글을 보면 **담임 선생님께 알리기** → 학교폭력 사안 절차로 연결

## 수업 시간에 할 때 (15분)

| 단계 | 시간 | 활동 |
|---|---|---|
| 도입 | 3분 | 안내 페이지 2회차 탭의 "이렇게 바꿔 봐요" 예시를 화면에 띄우고 "무엇이 달라졌나?" 함께 찾기 (비난 → 의견, 평가 → 질문) |
| 활동 | 8분 | 찾기 → 바꾸기 → 실천하기, 캡처 제출. 안전 규칙을 먼저 한 번 더 말해 주기 |
| 마무리 | 4분 | 잘 바꾼 표현 몇 개를 이름 없이 화면에 소개 → [예문 세트](examples.md) C 세트 중 현장실습 메시지 하나를 함께 고쳐 보기 |
