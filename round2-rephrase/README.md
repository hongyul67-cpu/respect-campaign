# 2회차 – 말 바꾸기 챌린지 (해보기)

**목표:** 공격적인 온라인 표현을 존중하는 표현으로 바꿔 쓰며 실천해 봅니다.
특성화고에 맞게 **현장실습·취업 상황**(직장 상사·동료에게 보내는 메시지)을 포함합니다.
**시간:** 종례 10분 · **제출:** 바꿔 쓴 문장 + 인증 캡처 1장

---

## 구글폼 구성 (퀴즈 형식)

폼 제목: `[존중 캠페인 2회차] 말 바꾸기 챌린지`

1. 학년 / 학과 / 반 / 학번·이름 (상점 부여용, 1회차와 같음)
2. **[객관식 퀴즈 3문항]** 더 존중하는 표현 고르기 → [예문 세트](examples.md)의 A 세트
   - 설정 → 퀴즈 → '퀴즈로 만들기' 켜기, 정답과 해설 입력
3. **[서술형 2문항]** 직접 바꿔 쓰기 → [예문 세트](examples.md)의 B 세트(일상)에서 1개, C 세트(현장실습·직장)에서 1개
4. **인증 캡처 업로드**: 바꾼 문장을 실제 메시지 입력창에 써 본 화면 (전송은 하지 않아도 됨)

> 반마다 다른 문제를 쓰지 않아도 됩니다. 문항 수는 **5개 이하**로 유지하세요.

---

## 종례 멘트 (1분)

> "오늘은 2회차 말 바꾸기 챌린지예요. 날카로운 말을 예의 있는 말로 바꾸는 퀴즈예요.
> 마지막 문제는 현장실습 가서 팀장님께 보내는 문자를 고쳐 쓰는 거예요. 실제로 쓸 일 있어요!
> 바꾼 문장을 카톡 입력창에 써 보고 캡처해서 올려 주세요. 학과별 우수작은 소개합니다."

---

## 우수작 선정

- 학과별로 1~2개를 고릅니다. 기준: 의도는 그대로 전하면서 상대를 존중했는지, 실제로 쓸 수 있는 말인지
- 선정작은 **문장만** 옮겨 `results/best.md`에 적습니다 (이름 없이 `기계과 2학년` 정도만)

## 마감 후 처리 체크리스트

- [ ] 응답 CSV → `data/raw/round2.csv`
- [ ] 학과별 우수작 → `results/best.md`
- [ ] 학급별 응답 수 집계: `python scripts/participation.py count data/raw/round2.csv --round 2`
- [ ] 대표 캡처 모자이크 → `results/`
- [ ] 응답 시트의 학번으로 **상점 부여** (우수작은 추가 상점)
- [ ] 루트 `README.md` 진행 현황 업데이트

## 2회만 운영한다면

이 회차는 건너뛰고, [예문 세트](examples.md)의 '바꾼 표현'을 3회차 카드 문구 예시로 씁니다.
