# 1회차 – 온라인 매너 알아보기 + 좋은 댓글 달기 (알기)

**오늘 할 것 두 가지**
1. **온라인 매너 알아보기**: 안내 페이지에서 매너 5가지를 1분 동안 읽습니다.
2. **좋은 댓글 하나 달고 캡처 보내기**: 실제로 댓글을 달고, 그 화면을 캡처해서 폼에 올립니다.

**시간:** 종례 5~10분 · **제출:** 내가 쓴 댓글 문장 + 캡처 1장 · **보상:** 참여 학생 상점

---

## 1. 온라인 매너 5가지 (안내 페이지와 같은 내용)

1. **보내기 전 3초**: 읽는 사람 입장에서 한 번 더 읽고 보냅니다.
2. **얼굴 보고 못 할 말은 온라인에서도 하지 않기**: 외모 평가, 패드립, 비꼬기 금지
3. **남의 사진·개인정보는 허락받고**: 친구 사진, 이름, 번호를 함부로 올리지 않습니다.
4. **단톡방 예의**: 늦은 밤 메시지는 자제하고, 읽씹 대신 "확인했어!" 한마디, 특정 친구를 빼고 말하지 않기
5. **확인 안 된 소문은 멈추기**: 퍼 나르기 전에 사실인지 확인합니다.

## 2. 좋은 댓글이란

| 이렇게 | 예시 |
|---|---|
| **구체적으로 칭찬** | "용접 과정을 이렇게 자세히 보여줘서 이해가 쏙 됐어요!" |
| **공감하기** | "저도 처음엔 어려웠는데 이 영상 보고 힘이 나요" |
| **응원하기** | "대회 준비 고생 많으셨어요. 좋은 결과 있을 거예요!" |
| **고마움 표현** | "좋은 정보 공유해 주셔서 감사합니다 🙂" |

**어디에 달까요?** (하나만 고르면 됩니다)
- 학교 공식 SNS 게시물
- 좋아하는 유튜브 영상, 뉴스 기사
- 친구나 가족 게시물
- SNS 계정이 없다면 **반 단톡방이나 가족 단톡방에 칭찬 한마디**도 인정합니다.

## 구글폼 문항

폼 제목: `[존중 캠페인 1회차] 온라인 매너 + 좋은 댓글 달기`

| # | 문항 | 형식 | 필수 | 메모 |
|---|---|---|---|---|
| 1 | 학년 | 객관식 (1/2/3학년) | ✅ | 참여율 집계용 |
| 2 | 학과 | 드롭다운 | ✅ | 학과 목록 입력 |
| 3 | 반 | 드롭다운 (1~N반) | ✅ | |
| 4 | 학번·이름 (상점 부여용) | 단답형 | ✅ | GitHub에 올리지 않음 |
| 5 | 오늘 가장 기억에 남는 온라인 매너 | 객관식 (위 5가지) | ✅ | '알기' 확인용, 결과보고 그래프 |
| 6 | 내가 단 **좋은 댓글** (그대로 옮겨 쓰기) | 단답형 | ✅ | 워드클라우드 재료 |
| 7 | 캡처 업로드 | 파일 업로드 (이미지, 1개, 10MB) | ✅ | |

폼 설명란에 넣을 문구:
> ① 안내 페이지에서 온라인 매너 5가지를 읽고
> ② 학교 SNS, 유튜브, 친구 게시물 등에 좋은 댓글을 하나 달고
> ③ 그 화면을 캡처해서 올려 주세요. 참여한 학생에게는 상점을 드립니다.
> ⚠ 내 계정 이름·프로필 사진, 다른 사람 이름은 가리고 캡처해 주세요.

**설정 체크**
- [ ] 파일 업로드 문항이 있으면 **응답자가 구글 로그인**을 해야 합니다. 학교 계정으로 로그인하도록 안내합니다.
- [ ] '응답 횟수 1회로 제한'을 켭니다. 응답 탭 → 'Sheets에 연결'을 해 두면 상점 부여와 집계가 편합니다.
- [ ] 폼 주소를 `docs/index.html`의 `FORMS[1]`에 넣습니다.
